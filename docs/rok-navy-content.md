# 대한민국 해군 자료 기반 문항 보강

근거 확인일: 2026-11-03. 공개 소개자료를 읽고 자체 제작한 교육용 문항이며 실제 자격시험 기출문제가 아닙니다. `published`는 출제 가능 상태이며 담당자 사람 검수를 의미하지 않습니다.

## 변경 범위

- 미 해군 출처 문항 32개와 영국 SSN-AUKUS 사례 1개를 제거했습니다. 관련 출처 10개와 연결된 보충 해설도 제거했습니다. 국내 함정인 정조대왕함의 이지스 전투체계 문항은 유지합니다.
- 해군 군사자료실 7개 항목에서 각 함종 12개씩 총 72문항을 작성했습니다. 임무·함명 기준·대표 함형·공개 장비의 구분에 집중했습니다.
- 기존 판단형 질문은 '가장 적절한', '가장 잘 설명한', '가장 부합하는' 대안을 묻도록 수정했습니다. 날짜·금액 계산·기관·명칭처럼 단일 사실을 묻는 질문은 사실형을 유지합니다. 새 문항의 해설은 정답 근거와 다른 보기와의 구별 기준을 두 문단으로 제공합니다.
- 기존 공통 기초 24문항은 계속 보관합니다. 현재 출제 344문항, 함종 164개·공통 상황형 60개·용어 120개, 출처 29개입니다.

## 원문과 확인한 항목

사용자가 제공한 `http://해군.한국/`은 대한민국 해군 공식 홈페이지를 프레임으로 표시합니다. 출처 링크는 해당 자료의 공식 HTTPS 주소로 직접 연결합니다. 군사자료실의 상세 소개는 이미지로 되어 있어 본문 소개 이미지와 표를 직접 열어 확인했습니다.

문항 `citation`에 해당 표·항목을 표시합니다. 이순신함과 충무공이순신함 비교 문항은 잠수함과 구축함 소개표를 함께 대조했습니다.

## 자료 해석과 출제 원칙

- 이미지 파일명의 날짜를 자료 게시일로 간주하지 않습니다. 게시일은 `null`, 자료 버전은 열람일을 명시합니다.
- 표에 등장하는 함정은 자료의 예시로 사용합니다. 누락된 이름으로 퇴역 여부를 추정하거나, 명단을 전체 보유 척수·당일 가동 전력으로 해석하지 않습니다.
- 장비 목록 비교는 해당 소개자료에 한정합니다. 다른 함형·개량 시점에도 모두 같은 장비 구성이 적용된다고 확대하지 않습니다.
- 임무 판단형은 위협 대상·수송 대상·지원 역할을 질문에 명시합니다. 여러 보기가 해군의 유효한 임무라도 질문의 대상과 목적에 가장 부합하는 하나를 고릅니다.
- 공개 소개 범위의 학습 문제를 작성합니다. 구체적인 전술·부설 위치·구조 절차나 공개되지 않은 성능을 추정하지 않습니다.
- 원문 이미지·사진은 사이트에 복제하지 않고, 사실을 재구성해 문항과 해설을 작성했습니다.

## 데이터·진행 기록

기존 인덱스 기반 문항의 순서는 유지합니다. 제거 대상은 개념 기반 ID를 쓰는 확장 문항이므로 기존 다른 ID는 바뀌지 않습니다. 신규 문항은 `q-rok-*`로 구분합니다. 기존과 같은 학습목표는 `concept`를 공유하여 한 회차 안에 반복 출제하지 않습니다.

기존 검증은 삭제·변경된 문항을 담은 진행 세션을 복원하지 않습니다. 저장된 완료 점수 기록은 유지합니다. 모든 함종에서 고유 개념 20개 이상과 역할·장비 문제 출제가 가능한지 자동 검사합니다.
